# Studio OS

A modern creative project management website developed as part of my CodeAlpha internship — Task 1.

## Overview

Studio OS is a polished web interface designed for a creative studio. It presents the studio's work, features, team, and design system through a responsive and interactive user experience.

## Sections

- **Home** — Main landing section introducing Studio OS
- **Features** — Highlights the platform's key capabilities
- **Work** — Project showcase with interactive project details
- **Team** — Creative team presentation
- **Design System** — Visual design tokens and interface elements

## Features

- Responsive user interface
- Modern dark-themed design
- Interactive project carousel
- Mobile navigation
- Scroll-based animations
- Interactive color swatches
- Creative project showcase
- Team section
- Design system showcase

## Technologies Used

- React
- TypeScript
- HTML5
- CSS3
- JavaScript
- Vite
